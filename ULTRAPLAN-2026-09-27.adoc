== Purpose

This document is the comprehensive plan to take the Chronicles of Slavia
repository from its current state — a prototype with extensive design canon,
working Zone A segment A1, and significant infrastructure debt — to a
repository that *looks structurally like the finished game will look*, with
all standards/debt/CI/CD issues resolved and every game system having a
clear home in the directory tree.

The goal is that after this plan is executed, the owner can concentrate
exclusively on game content — art, narrative, level design, sound — without
being blocked by repository infrastructure, missing directories, broken CI,
vestigial template scaffolding, or unclear architecture.

== Current state summary

* *Built:* Zone A segment A1 (52 tests, playable Bevy renderer, ESM complete
  but unwired, SGS data schema for Zone A)
* *Design canon:* 26 cross-referenced design documents, 8 ADRs, extensive
  world/character/mechanics specification
* *Debt:* 10 high, 14 medium, 8 low items in DEBT.adoc (across docs, code,
  proof, CI/CD, canon)
* *Template residue:* 94 files with unsubstituted `+PLACEHOLDER+` placeholders,
  vestigial Idris2/Zig FFI tree, banned-language toolchains in mise.toml,
  docs-template/ shipped inside a real project
* *Proof infrastructure:* 5 provers (Idris2, Lean4, Agda, Coq, TLA+) but
  zero proofs concern Slavia
* *CI/CD:* 31 workflow files, 3 disabled, several broken or misconfigured
* *Open issues:* 1 GitHub issue (#100 — 4 pre-existing red CI checks)

== Phase 4: Mathematical theory extensions

=== 4.1 Relevant theory from the estate

* *proven-tests-and-benches* — the 17×14 lattice for test provenance
  grading. Adopt the three-tier model for Slavia's test reporting.
* *echo-types* — proof-relevant fibers as typed witnesses for structured
  information loss. Relevant to the ESM's belief/delta model — a belief
  is a fiber over the baseline truth.
* *knot-knot* — knot theory for mathematical tangles. Relevant to the
  clothing pattern system's prerequisite tree (motifs combining).
* *phi-LAM* — typed action sequences and scheduling. Relevant to the
  ability system's type safety.

=== 4.2 Theory integration points

* The ESM's belief model (`baseline + deltas`) maps naturally to the
  echo-types framework — beliefs are typed witnesses of partial observation
* The opposition rule (stir/still) is a candidate for formal proof:
  `stir(still(x)) = x` and `still(stir(x)) = x`
* The determinism invariant is provable via Creusot contracts
* The living taxis diagnostic rule is a formal property: if
  `taxis_response(animal) ≠ expected(animal.nature)`, then
  `animal.state ∈ {possessed, corrupted, false, enchanted, afraid}`

== What this plan deliberately does NOT do

* *Does not build game content.* No art, no music, no level design, no
  dialogue. This is infrastructure only.
* *Does not resolve owner-only decisions.* Zone B's eight rulings,
  co-op vs switch-only for Chronicle II, the guardian spirit's exact
  form — these are creative decisions for the owner.
* *Does not add new game systems to the running code.* All new Rust
  modules are stubs with `todo!()` or empty trait definitions. The
  existing 52 tests must continue to pass.
* *Does not change the design canon.* The 26 design documents are the
  authoritative source; this plan creates homes for their implementation,
  not new design.
