[quote]
____
What do you become when the world breaks?
____

*Chronicles of Slavia* is a two-heroine Slavic-folkloric narrative game. Anya
stirs the world; Donna settles it. Neither can do the other's act — and every
living thing answers according to *its own nature*, not the girl's intent. The
game is authored as *data* over a pure, deterministic rules core; the renderer
is a replaceable skin.

The world principle, stated once:

[quote]
____
Slavia is not just geography. It is memory, medicine, folklore, and moral choice.
____

== Status at a glance

[cols="1,3",options="header"]
|===
| Thing | Where it stands

| Built and playable
| *Zone A* — the Border Path. Free-roam scene, two-heroine paper-doll rig, grove
  birds that answer by nature, the unstable crossing, the Rift's interruption, a
  full in-game menu with save/load/continue.

| Rules core
| `slavia-core` — the emotional grammar, living taxis, and SGS parsing. Depends on
  `serde` + `toml` only. Renders nothing.

| Formal proofs
| Five prover toolchains gate every push (Idris2, Lean4, Agda, Coq, TLA+), and a
  missing prover is fatal rather than skipped. Scope, stated honestly: the proofs
  cover a generic C ABI/FFI seam, *not* Slavia's game logic, and the TLA+ module is
  quarantined (unverified). See `docs/status/PROOF-STATUS.adoc`.

| Designed, not built
| Zone A segments *A2–A5* (`docs/design/23`) and *Zone B — Fracture Line*
  (`docs/design/24`), whose eight open questions are awaiting owner rulings
  (`docs/design/25`, tracked in issue #63).

| Deliberately unwired
| The *ESM* (belief / intent / decay — the theory-of-mind substrate). Complete and
  tested headless; wired to no scene yet, by ADR-0004.
|===

Maturity is *experimental*. Version is `0.0.0` on both crates, deliberately: nothing
here is released.

== Play it

The game is Rust + https://bevy.org[Bevy] 0.15. You need a Rust toolchain and a
display (WSLg/XWayland works).

[source,sh]
----
git clone https://github.com/metadatastician/chronicles-of-slavia
cd chronicles-of-slavia/engine
cargo run -p slavia-zone-a
----

There is also a launcher wrapper, `chronicles-of-slavia-launcher.sh`, which looks
for a release build.

=== Controls

[cols="1,3",options="header"]
|===
| Key | Action

| `A` / `D` or `←` / `→` | Move
| `Space` or `↑` | Jump
| `Tab` | Switch between Anya and Donna
| `E` | Reach out to the birds
| `F` | Settle the crossing (Donna), then cross it
| `R` | Awaken the Rift
| `Esc` | Back to the menu
|===

`F` is one key doing both halves of the co-op grammar: Donna settles what is
unsettled, and whoever stands at a settled crossing may cross it. That is the game
in miniature — Anya crosses *because Donna made the path hold*.

=== What a run looks like

Seven beats, walked left to right: forest entrance → bird grove → shrine
(_"Two lands, one heart."_) → the stream crossing → ridge path → overlook →
fracture prelude. Five of them are *understanding beats* the game tracks; the
menu's Continue resumes exactly where you left off.

== The idea

=== The emotional grammar

Anya *quickens*: she excites, stirs, emboldens, agitates. Donna *settles*: she
calms, slows, quietens, reassures. These are not two skins on one chaos/order
slider — they are *opposed verbs*, and the opposition is load-bearing. Only Donna
can steady; only Anya can stir; the puzzles live in the gap.

=== Living taxis

Animals are not tools, pets, buttons, or units. The girls do not command them —
they change the rhythm of the living world, and each creature answers *according
to its own nature*. When an animal answers wrongly, that is not a bug in the
world; it is the world telling you something — corruption, enchantment, false
life, or the Rift's influence.

=== The two lands

Anya carries Carpathian/Ukrainian motifs (blue and yellow, red embroidery, a
forward-moving silhouette, hair slightly chaotic). Donna carries Rhodope/Bulgarian
ones (white, green and red, an upright grounded stance, hair in a tidy bun). The
shrine between them reads _"Two lands, one heart."_ Zone B is where that stitch
tears.

== Architecture — game as data

Three layers, described in full in `ARCHITECTURE.md` and ADR-0002:

[cols="1,3",options="header"]
|===
| Layer | What it is

| *L1 — Slavia Game Spec (SGS)*
| Declarative TOML describing a zone: characters, animals, beats.
  `engine/slavia-core/data/*.sgs.toml`. *Change the game by changing this data.*
  ADR-0006 makes the SGS the public authoring schema.

| *L2 — `slavia-core`*
| The pure rules core: the emotional grammar, living taxis, spec parsing, and the
  ESM. Deterministic, renderer-free, wasm-friendly, `serde` + `toml` only.

| *L3 — `slavia-zone-a`*
| The Bevy renderer and menu (ADR-0003). A skin over L2 — swappable without
  touching the design.
|===

The point of the layering is that the game's *meaning* lives in data and a proven
core, so the runtime can be replaced without renegotiating the design.

== Develop

[source,sh]
----
just test        # cargo test -p slavia-core, then slavia-zone-a headless (no display needed)
just quality     # fmt-check + lint + test
just proof-check-all   # all five provers (needs the toolchains; see .github/workflows/proof-gate.yml)
----

`just test` is the golden path recorded in `ANCHOR.a2ml`: Zone A's five-beat spec
holds, the ESM testbed passes, and L2 stays deterministic — same seed and same
inputs give the same result.

Known local wrinkle: `just` must be *>= 1.33* (the Justfile uses `import?`, and
older versions run imported recipes from the wrong directory). CI pins 1.56.0.

== Design canon

The design is *written down*, extensively, and the documents are the source the
SGS is compiled from. Start at `docs/design/00-start-here.md`. Load-bearing ones:

* `01-world-principle.md` — what Slavia is
* `06-attunement-and-modifiers.md` — the opposition mechanic
* `08-level1-five-zone-map.md` — Zones A–E, and the rule that *nothing past Zone A
  is built until Zone A holds*
* `20-cognitive-npcs-and-theory-of-mind.md` — the ESM's design
* `22-narrative-structure-per-chronicle.md` — Kishōtenketsu / chiasmus / Fichtean,
  one shape per Chronicle
* `23-level-scope-and-pacing.md` — the A1–A5 scale-up
* `24-zone-b-fracture-line.md` + `25-zone-b-decision-sheet.md` — Zone B and its
  eight pending rulings

== Not this project

Boundaries, kept deliberately: this is *not* rsr-template-repo (the template it was
instantiated from), *not* IDApTIK (the estate's other game), *not* Universal Modding
Studio (an independent authoring platform in which Slavia is merely a profile), *not*
an engine-owned ontology (Bevy is a chosen skin, the core stays renderer-neutral),
*not* a multiplayer game (parked), and *not* an AI or neurosymbolic research project.
