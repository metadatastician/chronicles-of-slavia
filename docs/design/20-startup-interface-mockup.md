# Chronicles of Slavia startup-interface mock-up

`chronicles-landing-page.html` is the standalone Chronicles of Slavia
startup-interface outline provided on 2026-07-25. It is retained as an
executable HTML design reference beside the game's other design documents.

Its menus, status values, saves, launch actions, and runtime integrations are
simulated in the browser. The page does not establish that those application
services exist, and it does not change the currently bounded Zone A scope.
Future implementation must obtain game state through the Slavia-owned
application/runtime boundary and must not move Slavia-specific ontology into
Universal Modding Studio Core.
