[IMPORTANT]
.Caveat 1 — what these proofs are about
====
Every one of the 7 requirements concerns a *generic C ABI/FFI seam* inherited from the
RSR template: pointer non-nullity, struct layout and alignment, per-platform type
sizes, FFI return types, and API type well-formedness.

*None of them is about Slavia.* No proof yet states an invariant of the emotional
grammar, the living-taxis rules, determinism, or the ESM. Those properties are
currently held by the Rust test suite (52 tests), which is real evidence but is not a
proof. Two prover manifests say so in their own words: the Agda and Coq entries both
read _"still generic template content, not a chronicles invariant"_.
====

[IMPORTANT]
.Caveat 2 — TLA+ verifies nothing today
====
`verification/proofs/tlaplus/StateMachine.tla` is marked *quarantine*, not *gated* —
_"tla2sany not available in current environment; proof cannot be verified"_.

Under `scripts/check-proofs.sh`, a quarantined module passes the check by *continuing
to fail*. So `proof-check-tla` reporting PASS means "the known-broken module is still
broken, as recorded" — it does **not** mean a TLA+ specification was model-checked.
The gate is honest about this by design; a reader skimming a green board might not be.

The quarantine note may now be stale: the Proof Gate workflow does install
`tla2tools.jar` and a JRE. Re-evaluating whether `StateMachine.tla` can be promoted to
`gated` is tracked in `DEBT.adoc`.

== How this is checked

`scripts/check-proofs.sh <prover>` is the single source of truth; both CI and a local
`just proof-check-all` call it, so a green local run and a green CI run mean the same
thing. It exists because four earlier "checks that could not fail" let non-compiling
proofs sit in estate repos for months while status files said "proved" — including the
trap that `idris2 --check` *exits 0 on a missing import* while printing `Error:`. The
script therefore requires exit 0 **and** no `Error:` line.

`.github/workflows/proof-gate.yml` provisions all five toolchains and treats a missing
prover as *fatal, never a skip*: an unrun prover means the proofs are unverified, and
the gate declines to certify them.

== What would make this meaningful for Slavia

In rough order of value, tracked in `PROOF-NEEDS.adoc` and `DEBT.adoc`:

. *Determinism (INV).* L2's central claim — same seed and same inputs give the same
  result — is currently test-evidenced, not proven.
. *The opposition invariant (DOM).* Only Donna can settle; only Anya can stir; no state
  lets one perform the other's act. This is the rule the whole game and Zone B's design
  rest on.
. *Living-taxis soundness (DOM).* An animal's response is a function of its own nature
  and the acting girl — never of the girl alone.
. *ESM belief locality (INV).* Belief is baseline plus an entity's own deltas; no
  entity reads another's private belief.

Until at least one of these lands, the accurate summary of this repo's formal position
is: *a rigorously gated ABI proof suite, and a well-tested but unproven game core.*
