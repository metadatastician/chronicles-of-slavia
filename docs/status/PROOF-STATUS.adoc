Each statement is deliberately about the checker and the named module. None
implies that the game, Rust implementation, or interface seam is proved.

== Interface-proof gap

The two Idris2 trees have different roles:

* `verification/proofs/idris2/` contains generic model propositions accepted by
  the proof gate.
* `src/interface/Abi/` contains an inherited foreign-interface scaffold that
  typechecks as `abi.ipkg`, but uses `IO`, `PrimIO`, and `primIO` and declares
  `rsr_*` foreign symbols.

The Zig scaffold exports unresolved `{{project}}_*` names, is not compiled by
its empty `build.zig`, and has no unified Hexadeca API dependency. No generated
header exists under `src/interface/generated/abi/`. Consequently there is no
evidence that the generic Idris proofs describe, preserve, or even name the Zig
surface. A proof about one model is not an ABI-conformance proof for another.

== Required next proofs

. *Rust/Creusot determinism:* same initial state and input sequence imply the
  same `slavia-core` state and observations.
. *Opposition invariant:* only Anya stirs and only Donna settles, with no state
  permitting either to perform the other's act.
. *Living-taxis soundness:* response depends on the animal's nature and acting
  character, never on character alone.
. *ESM belief locality:* an entity's belief is the baseline plus only its own
  deltas.
. *Traversal refinement:* the renderer/session transition preserves the L2
  rule-state contract.
. *Interface decision:* remove the unused ABI/FFI scaffolding, or declare and
  implement a real Idris2-contract/Zig-Hexadeca seam and prove its generated
  boundary. Scaffolding is not a third outcome.
