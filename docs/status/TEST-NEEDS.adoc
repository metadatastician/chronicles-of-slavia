== Legacy template tests

`scripts/validate-template.sh` and
`tests/e2e/template_instantiation_test.sh` were inherited from the generic RSR
template. They are *not product E2E coverage* for the Bevy game and are not
called by the current E2E workflow.

The recovery run corrected their obsolete workflow requirement
(`runtime-policy.yml` supersedes `npm-bun-blocker.yml` and `ts-blocker.yml`) and
made the temporary copy/cache boundaries safe. The isolated copy then passed
structure validation, Zig builds, and Idris typechecking, before correctly
revealing that the already-instantiated repository still contains generic
template tokens and documents. Therefore the overall template-instantiation
script remains *not applicable / not passing*; it must not be presented as a
project test.

PR #77's repaired `find -exec` argument boundary was tested independently with
a planted `{{PROJECT}}` token. The token was replaced and the expected value was
observed. That validates the repair without pretending the legacy suite is a
valid game-level E2E test.

== Highest-priority gaps

. Add renderer capability tests for menu navigation, input mapping, accessibility
  settings consumption, and save/load behavior. Six session tests do not cover
  those surfaces.
. Add and gate Creusot contracts for the Rust core's named invariants; do not
  translate selected passing examples into universal proof claims.
. Replace the zero-assertion `tests/e2e.sh` path with a real game smoke test, and
  make `.github/workflows/e2e.yml` react to `engine/**` changes.
. Add a non-renderer coverage view or targeted tests before raising the coverage
  floor; renderer-inclusive coverage is currently the measured contract.
. Review and remove or remediate the five allowed RustSec warnings instead of
  treating the audit allowlist as permanent.
. Resolve the ABI/FFI capability decision: remove the unused interface scaffold,
  or implement and prove a real Idris2 ABI / Zig unified-Hexadeca boundary.
