# Zone A Prototype

Open `index.html` in a browser.

## Controls

- A/D or arrows: move
- Space: jump
- Tab: switch character
- E: interact
- R: restart

## What this tests

- Character switching
- Donna stabilizing the bridge
- Anya crossing after Donna stabilizes
- Birds responding differently to Anya and Donna
- Rift interruption at the end
