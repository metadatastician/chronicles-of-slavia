= Slavia engine

A layered, renderer-agnostic engine for Chronicles of Slavia. The point of the
layering is *maximum flexibility*: the game's meaning lives in data and a pure
rules core, so the runtime (browser, Godot, native) can be swapped without
touching the design.

[cols="1,3a"]
|===
| Layer | What it is

| *L1 — Slavia Game Spec (SGS)*
| Declarative data describing a zone: characters, animals, beats.
  `slavia-core/data/*.sgs.toml`. The design canon in `docs/design/` is compiled
  into this. Change the game by changing this data.

| *L2 — `slavia-core`*
| The pure rules core — the emotional grammar (Anya stirs / Donna settles / the
  animal's nature decides / Donna steadies what Anya crosses / the Rift
  interrupts). Renders nothing. This is the *sacred logic*, and it is proven by
  tests before any renderer exists.

| *L3 — renderer*
| A swappable skin over L2. First spike lives in `slavia-zone-a` — a **Bevy**
  renderer for Zone A (schematic, coloured blocks). It holds only view state and
  forwards input; every rule decision goes through `Session` → `slavia-core`.
  The *final* engine decision (Bevy / Fyrox / other) is still M2, made on
  evidence from this working spike rather than up front.
|===

== Run the tests

[source,sh]
----
cd engine
cargo test -p slavia-core                          # the rules core (L2)
cargo test -p slavia-zone-a --no-default-features  # the play controller, no Bevy
----

`slavia-core/tests/zone_a.rs` encodes Zone A's five-beat prototype success
condition (`docs/design/00-start-here.md`) as executable assertions; the
`slavia-zone-a` session test walks the same five beats through the exact intents
the renderer calls. If both are green, the sacred logic and its wiring hold —
no display needed.

== Play Zone A

[source,sh]
----
cd engine
cargo run -p slavia-zone-a
----

Opens a window (needs a display — under WSL2 this is WSLg). Controls print to the
terminal: `Tab` switch girl, `A/D`/arrows move, `E` reach out to the birds, `S`
settle the crossing (Donna only), `C` cross, `R` awaken the Rift, `Esc` quit.
The birds recolour by response, the crossing solidifies when settled, the sky
darkens at the Fracture, and five pips along the top fill as each beat happens.

Build note: uses Bevy's `x11` backend only (no `wayland`), so it builds without
`libwayland-dev`. Add the `wayland` feature back if that dev lib is installed.

== Status

Milestone *M1* — a first playable renderer (Bevy) over the proven core.
Next: *M2*, the deliberate engine decision, made on evidence from this spike.
