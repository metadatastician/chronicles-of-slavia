# Chronicles of Slavia Prototype

Private exploratory prototype.

A mythic 2D puzzle-platform prototype about two girls whose bond shapes a world of memory, medicine, folklore, and moral choice.

**What do you become when the world breaks?**

Current focus: Level 1, Zone A — Border Path.

## Quick Start

Open `prototype/zone-a/index.html` in a web browser.

## Controls

- **A/D** or **Arrow Keys**: Move
- **Space**: Jump
- **Tab**: Switch character
- **E**: Interact
- **R**: Restart
